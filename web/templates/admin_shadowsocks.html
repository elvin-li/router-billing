加密代理 (Shadowsocks)

内置的 Shadowsocks AEAD 代理 · 给需要出站加密代理的本地设备一个扫码即用的分享链接

{{if not .Enabled}}

Shadowsocks 代理默认关闭。启用后，本机可作为本地加密代理，客户端扫码即可配置。 它与 MAC 计费 / 强制门户完全独立，不会影响现有计费逻辑。

在 config.yaml 中添加以下配置后重启服务： 

shadowsocks:
  enabled: true
  listen: "192.168.5.1:8388"   # 仅监听 LAN 地址，切勿绑定付费 SSID / WAN
  method: "chacha20-ietf-poly1305"
  password: "<运行 --gen-ss-password 生成>"

生成强密码：router-billing --gen-ss-password； 生成分享链接：router-billing --ss-uri。

{{end}}

安全建议

  • 务必只监听 LAN 地址（如 br-lan / Free_WiFi 的网关 IP），不要绑定付费 SSID —— 否则未付费用户可绕过门户上网。
  • 暴露到公网 (WAN) 有风险；如确需远程使用，请配合强密码与 allowed_cidrs，并在防火墙上限制来源。
  • 轮换密码：--gen-ss-password 生成新值，替换 config 后重启；旧链接立即失效。
